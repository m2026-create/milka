# 🥛 우유 꿀꺽 출석부

우유갑에 자기 이름을 쓰고 사진을 찍으면, 티처블 머신이 **그 학생의 글씨인지**
확인해 주고 도장을 찍어 주는 교실용 웹앱입니다.
연속으로 성공하면 쿠폰이 쌓입니다.

- 설치 없이 **브라우저만** 있으면 됩니다
- 기록은 **그 기기 안에만** 저장됩니다 (서버로 보내지 않음)
- 깃허브 Pages에 올리면 교실 태블릿에서 바로 쓸 수 있습니다

---

## 📁 파일 구성

```
우유출석_프로그램/
├─ index.html              화면 구조
├─ css/style.css           꾸미기
├─ js/config.js            ⭐ 선생님이 고치는 설정 (명단, 목표일수 등)
├─ js/streak.js            연속 일수·쿠폰 계산 규칙
├─ js/store.js             기록 저장/불러오기
├─ js/app.js               전체 흐름 (카메라, 판별, 결과)
├─ model/                  ⭐ 티처블 머신에서 받은 모델 파일 3개를 넣는 곳
└─ tools/
   ├─ augment_images.py    [파이썬] 학습 사진 늘리기
   ├─ report.py            [파이썬] 기록 분석 → 엑셀(CSV)
   ├─ requirements.txt
   └─ devserver.cjs        로컬 테스트용 작은 서버 (Node)
```

## 1단계 · 사진 모으기

학생마다 우유갑(또는 종이)에 **자기 이름을 크게** 쓰게 하고 사진을 찍습니다.

**잘 되는 사진의 조건**
- 이름이 화면의 **절반 이상**을 차지하게 가까이
- 밝은 곳, 그림자가 글씨를 가리지 않게
- 한 명당 **5~10장** (각도·거리를 조금씩 다르게)

사진을 `tools/raw/학생이름/` 폴더에 넣습니다.

```
tools/raw/김하준/  ← 김하준이 쓴 사진 5~10장
tools/raw/이서아/
```

## 2단계 · 사진 늘리기 (파이썬) — *선택 사항*

5장으로는 모델이 잘 못 맞힙니다. 컴퓨터가 밝기·회전을 조금씩 바꿔
**한 장을 13장으로** 불려 줍니다.

> ⚠️ **이 단계에만 파이썬이 필요합니다.** 앱 자체는 파이썬 없이 돌아갑니다.
> 지금 이 컴퓨터에는 파이썬이 설치돼 있지 않습니다
> (`python`을 치면 Microsoft Store 안내만 뜨는 상태).
> [python.org](https://www.python.org/downloads/)에서 설치할 때
> **"Add python.exe to PATH"** 를 꼭 체크하세요.
> 설치가 번거로우면 이 단계를 건너뛰고,
> 티처블 머신에서 웹캠으로 직접 많이 찍어도 됩니다.

```bash
pip install -r tools/requirements.txt
```

```bash
python tools/augment_images.py
```

결과가 `tools/out/학생이름/` 에 생깁니다.
(이 단계를 건너뛰고 티처블 머신에서 직접 웹캠으로 많이 찍어도 됩니다)

## 3단계 · 티처블 머신 학습

1. [teachablemachine.withgoogle.com](https://teachablemachine.withgoogle.com) → **이미지 프로젝트** → 표준 이미지 모델
2. 클래스 이름을 **학생 이름과 똑같이** 바꿉니다 (예: `김하준`)
3. 각 클래스에 **업로드** → `tools/out/학생이름/` 사진 전부 넣기
4. ⭐ **`우유갑아님` 클래스를 꼭 하나 더 만듭니다**
   → 빈 책상, 손, 필통, 다른 물건 사진 30장 이상
   → 이게 없으면 **아무거나 찍어도 통과**됩니다
5. **모델 학습시키기** (에포크 50, 배치 16 기본값으로 충분)
6. **모델 내보내기** → 아래 둘 중 하나

### ⚠️ "다운로드"가 두 종류입니다 — 헷갈리기 쉬운 부분

| 메뉴 | 받는 것 | 이 앱에서 |
|---|---|---|
| ☰ → **프로젝트를 파일로 다운로드** | `.tm` 파일 | ❌ **못 씁니다.** 티처블 머신에서 다시 열어 편집할 때만 쓰는 파일 |
| **모델 내보내기** → Tensorflow.js → **다운로드** | `.zip` (파일 3개) | ✅ **이것을 받으세요** |
| **모델 내보내기** → Tensorflow.js → **업로드** | https 주소 | ✅ 이것도 됩니다 |

> Tensorflow.js 탭이어야 합니다. **Tensorflow**(.h5)나 **Tensorflow Lite**는
> 파이썬·앱 전용이라 브라우저에서 못 씁니다.

## 4단계 · 앱에 연결

앱을 열고 오른쪽 위 **⚙️** → 비밀번호 `1234` (기본값)

### 방법 1 — 모델 파일을 프로젝트에 넣기 (권장)

받은 zip을 풀면 **파일 3개**가 나옵니다. 이 3개를 `model/` 폴더에 바로 넣으세요.

```
우유출석_프로그램/model/
├─ model.json
├─ weights.bin
└─ metadata.json
```

> 압축을 풀면 `converted_keras` 같은 폴더가 한 겹 더 생기는 경우가 많습니다.
> `model/converted_keras/model.json` ❌ → `model/model.json` ⭕

그 다음 ⚙️에서 **📁 model/ 폴더 쓰기** 버튼을 누르면 끝입니다.

**이 방식의 장점**
- 모델이 구글 서버에 올라가지 않습니다 (개인정보 측면에서 더 안전)
- 교실 와이파이가 느려도 빠르게 뜹니다
- 티처블 머신 공유 링크가 사라져도 계속 작동합니다

### 방법 2 — 공유 링크 쓰기

**업로드(공유 가능한 링크)**로 받은 주소를 칸에 붙여넣습니다.
`https://teachablemachine.withgoogle.com/models/AbCdEfGh/`

### 공통

1. **모델 연결 확인** 버튼 → 명단과 클래스 이름이 일치하는지 검사해 줍니다
2. **우리 반 명단**을 한 줄에 한 명씩 입력

```
김하준, 김하준, 🐰
이서아, 이서아, 🐱
```

> `이름, 티처블머신클래스명, 이모지` 순서입니다.
> 클래스명을 학생 이름으로 만들었다면 두 번째 칸은 생략해도 됩니다.

4. **💾 저장하기**

`js/config.js`를 직접 고쳐도 됩니다 (처음 켜질 때의 기본값).

## 🎮 학생이 쓰는 법

1. 자기 이름 카드 누르기
2. 우유갑 이름을 네모 칸에 맞추기
3. **📸 찰칵!**
4. 통과하면 🥛 도장, 연속 5번이면 🎟️ 쿠폰

이미 한 학생 카드는 **완료!** 표시가 붙고, 누르면 자기 기록을 봅니다.

### 📷 카메라 바꾸기

카메라가 두 개 이상인 기기(휴대폰·태블릿·웹캠 두 대)에서는
촬영 화면 오른쪽 위에 **🔄 단추**가 나타납니다.
누를 때마다 앞 카메라 ↔ 뒤 카메라로 바뀌고, 웹캠이 여러 개면 차례로 넘어갑니다.

- 기본값은 **뒤 카메라**입니다 (우유갑을 찍기 편하게)
- 고른 카메라는 **그 기기에만 기억**되어, 다음에 켤 때 그대로 열립니다
- 카메라가 하나뿐인 기기에서는 단추가 보이지 않습니다
- 기억해 둔 카메라가 사라지면(웹캠을 뽑는 등) 자동으로 기본 카메라로 돌아갑니다

## 🚀 깃허브에 올려 배포하기

```bash
git init
git add .
git commit -m "우유 꿀꺽 출석부"
git branch -M main
git remote add origin https://github.com/내아이디/milk-attendance.git

```

그 다음 깃허브 저장소에서
**Settings → Pages → Source: `main` / `(root)` → Save**

몇 분 뒤 `https://내아이디.github.io/milk-attendance/` 로 열립니다.

> **카메라는 `https://` 에서만 작동합니다.** 깃허브 Pages는 https라서 괜찮습니다.
> 내 컴퓨터에서 시험할 때는 `http://localhost` 로 열어야 합니다
> (파일을 두 번 눌러 `file://` 로 열면 카메라가 안 켜집니다).

로컬 테스트 (Node가 있으면 설치 없이 바로 됩니다):
```bash
node tools/devserver.cjs
```
→ 브라우저에서 `http://localhost:8777`

파이썬이 설치돼 있다면 이것도 됩니다:
```bash
python -m http.server 8000
```

## ⚙️ 판별 기준 이해하기

학생이 **먼저 자기 이름을 고르므로**, 모델에게 "누구야?"가 아니라
**"이게 김하준 글씨 맞아?"** 를 묻습니다. 그래서 정확도가 높습니다.

통과하려면 **세 가지를 모두** 만족해야 합니다.

| 조건 | 기본값 | 뜻 |
|---|---|---|
| 1위가 내 이름 | — | 다른 친구 글씨면 실패 |
| 1위 확률 ≥ `confidenceMin` | 0.80 | 흐릿하면 실패 |
| 1위−2위 차이 ≥ `marginMin` | 0.20 | 헷갈리면 실패 |

**너무 안 통과될 때** → `confidenceMin` 0.65, `marginMin` 0.10 으로 낮추기
**아무거나 통과될 때** → 값을 올리고, `우유갑아님` 클래스 사진을 더 넣기

모델이 계속 못 맞히는 학생이 있으면 ⚙️ 현황표의 **오늘인정** 버튼으로
선생님이 직접 처리할 수 있습니다. (수업이 멈추지 않게 하는 안전장치)

## 🔒 개인정보 유의사항

- 사진은 **기본적으로 저장되지 않습니다** (판별에만 사용).
  ⚙️에서 켤 수 있지만 **끈 상태를 권장**합니다.
- 기록은 그 기기의 브라우저 안에만 있습니다. 서버로 가지 않습니다.
- 내보낸 JSON에는 학생 이름이 들어 있습니다. **깃허브에 올리지 마세요.**
  (`.gitignore`에 `*.backup.json`, `backup/`, `tools/out/`을 넣어 두었습니다)
- 티처블 머신에서 **모델 업로드**를 하면 학습된 모델이 구글 서버에 올라갑니다.
  사진 자체는 올라가지 않지만, 가정통신문으로 안내하시는 편이 안전합니다.
- 브라우저 데이터를 지우면 기록도 사라집니다. **주 1회 정도 내보내기로 백업**하세요.

## 🧯 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| 카메라가 안 켜짐 | `https` 또는 `localhost`인지 확인 / 브라우저 카메라 권한 허용 |
| 엉뚱한 카메라가 켜짐 | 촬영 화면 오른쪽 위 **🔄** 단추로 앞/뒤 카메라를 바꾸세요 (그 기기에 기억됩니다) |
| "모델을 불러오지 못했어요" (링크 방식) | 주소 끝에 `/` 가 있는지, **업로드**까지 눌렀는지 확인 |
| "모델을 불러오지 못했어요" (폴더 방식) | `model/` 안에 파일 3개가 **바로** 있는지 확인 (폴더 한 겹 더 ❌) |
| `.tm` 파일을 넣었는데 안 됨 | `.tm`은 편집용입니다. 모델 내보내기 → Tensorflow.js → 다운로드로 다시 받으세요 |
| 모델에 없는 클래스 경고 | 명단의 클래스명과 티처블 머신 클래스명의 **철자·공백** 일치시키기 |
| 다른 친구로 인식됨 | 그 학생 사진을 더 찍어 다시 학습 / 이름을 더 크고 진하게 쓰게 하기 |
| 연속이 자꾸 끊김 | ⚙️에서 쉬는 날(현장학습·재량휴업일)을 `쉬는 날` 칸에 추가 |

## 💡 수업으로 확장하기

- **인공지능 학습 원리** — 사진을 5장만 넣었을 때 vs 50장 넣었을 때 비교
- **데이터 편향** — 밝은 곳 사진만 학습시키고 어두운 곳에서 찍어 보기
- **분류의 한계** — 비슷한 글씨를 가진 두 친구를 모델이 헷갈리는 모습 관찰
- **데이터 윤리** — "내 글씨 데이터를 컴퓨터가 갖는다는 것"에 대해 이야기 나누기
